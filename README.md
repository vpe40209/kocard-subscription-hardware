## KOCARD 的软件和硬件分别干什么

App 端目前覆盖 iOS 和 Android，主要能力是这几块：

- 智能相册同步，把手机相册自动备份到指定存储设备，腾出手机空间
- 多目标传输，一次把文件复制到本地、云盘、NAS 或者剪辑软件，官方点名支持的有 Google Drive、Dropbox、个人 NAS 和剪映
- 智能转码，把视频转成 10-bit HEVC 格式，官方说体积最高能减小 80%
- Hash 校验，拷贝完成后核对文件完整性，防止倒素材时出现损坏
- AI 选图和 AI 修图，自动筛掉重复和废片，给照片打分、做增强

硬件 KOCARD GO 是另一条线。它是一块能吸附在手机、相机、平板或笔记本上的移动 SSD，内置 SD 和 TF 双卡槽，规格是 UHS-II/4.0，标称传输速度约 1000MB/s，用配套读卡器读 SD 卡最高约 312MB/s。整机功耗低于 5W，可以直接靠手机供电，也能接 PD 电源长时间工作。

所以“KOCARD 多少钱”这个问题没有唯一答案。软件是订阅制，硬件是一次性买断，两个价格体系，别拿一个数字概括整套东西。

## KOCARD GO 这块硬件适合什么人

判断标准很朴素，看你一个月有几次“拍完卡、身边没电脑、又必须马上处理素材”的场合。

有这种场合的人，硬件的价值落在几个具体的点上。双卡槽意味着不用额外带读卡器，相机卡和无人机卡可以轮着插。磁吸结构让它能直接贴在手机背面或者笔记本 A 面，不用找地方摊开一堆线和设备。5W 以下的功耗意味着手机就能带动它，不必非得找插座。这些设计都是冲着“现场”两个字去的。

没有这种场合的人，硬件大概率吃灰。办公室里把卡插进读卡器、再拷到电脑硬盘，这条路径其实更快也更稳。1000MB/s 的 SSD 速度在桌面场景里发挥不出来，因为瓶颈在读卡那一段。SD 卡读速上限约 312MB/s，这个数字才是你实际倒卡时的天花板，硬盘再快也白搭。

还有一点值得说，KOCARD GO 的容量是固定的，买多大就是多大，不像硬盘盒能自己换盘。长期拍高码率视频的人，一开始就该按一年的素材量估容量，别按单个项目估。
